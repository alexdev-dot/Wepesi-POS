# Wepesi-POS Demo Video Guide

## Application Overview
**Wepesi-POS** is a comprehensive Point of Sale system built with Next.js, featuring:
- Modern, responsive UI with Tailwind CSS
- Real-time inventory management
- Customer relationship management
- Sales analytics and reporting
- Multi-payment method support (Cash, M-Pesa, Card)
- Barcode generation and scanning
- Receipt customization
- Multi-user access with role-based permissions

## Technical Setup for Recording

### Recommended Tools
- **Screen Recording**: OBS Studio, Camtasia, or Loom
- **Microphone**: External USB microphone for clear audio
- **Browser**: Chrome or Firefox in full-screen mode
- **Resolution**: 1920x1080 (1080p)

### Pre-Recording Checklist
1. **Start the development server**: `npm run dev`
2. **Clear browser cache** for fresh start
3. **Disable browser extensions** that might interfere
4. **Set up dummy data** - ensure all mock data is loaded
5. **Test all flows** before recording to avoid errors
6. **Prepare script** and practice timing

### Recording Tips
- Use smooth mouse movements
- Pause briefly between actions for clarity
- Highlight important elements with cursor
- Maintain consistent pacing
- Record in a quiet environment
- Do multiple takes if needed

### Post-Production
- Add intro/outro screens with branding
- Include background music (subtle)
- Add text overlays for key features
- Ensure audio levels are consistent
- Export in high quality (1080p, 60fps recommended)

## Troubleshooting Common Issues

### Data Not Loading
- Ensure development server is running
- Check browser console for errors
- Refresh the page

### Images Not Displaying
- Verify image paths in public/products/
- Check image file formats (jpg, avif supported)

### Performance Issues
- Close other browser tabs
- Clear browser cache
- Check system resources
